۱. نمای کلی معماری
-----------------------------------------------------
- نام پلتفرم: Pahnavarkar
- دامنه اصلی: https://pahnavarkar.com

- Authentication:

  - موبایل: Token-based (Sanctum) با محدودیت تعداد دستگاه (بررسی در زمان ورود)

- پلن‌ها: Free, Premium (یک‌ماهه و سه‌ماهه) + دوره آزمایشی ۷ روزه با جدول اشتراک جداگانه (بدون نگهداری فیلدهای اضافه در users)
- کیف پول: موجودی ریالی با پشتیبانی از پرداخت ترکیبی (کیف پول + درگاه)، محدودیت تراکنش روزانه، جلوگیری از Race Condition با Lock
- پرداخت آنلاین: لایه انتزاعی با پشتیبانی از درگاه‌های سداد، سِپ، زرین‌پال و پی‌لینک، امضای HMAC برای Webhook و Callback، Idempotency Key، جدول Payment Attempts
- مدیریت وب‌هوک و Callback: تطبیق‌پذیری با هر دو روش، تأیید امضا و بررسی وضعیت تراکنش
- کد تخفیف: عمومی و اختصاصی کاربر با اعتبارسنجی پیشرفته و کنترل همزمانی اتمی
- ارسال پیامک: لایه انتزاعی با صف (Queue) و Failover
- اعلان‌ها: سیستم Notifications لاراول با کانال‌های SMS، دیتابیس، ایمیل و Push (FCM)
- فایل‌ها: ذخیره در S3 با Fallback به Local و CDN
- DevOps: VPS + Laravel Forge + GitHub Actions + EAS، پشتیبان‌گیری با spatie/laravel-backup و تست بازیابی خودکار
- مانیتورینگ: Sentry + UptimeRobot + Laravel Pulse + لاگ فعالیت کاربران + مانیتورینگ صف‌ها + جمع‌آوری لاگ متمرکز (Loki) + هشداردهی

- تست: Unit/Feature با Mock سرویس‌های خارجی، Load Testing با K6 و Threshold، پوشش کد حداقل ۸۰٪، اجرای خودکار تست‌ها در CI/CD

RateLimiter::for('login', function (Request $request) {
    $key = $request->input('email') ?? $request->input('phone') ?? $request->ip();
    return [
        Limit::perMinute(5)->by($key),
        Limit::perHour(20)->by($key),
        Limit::perMinute(10)->by($request->ip()),
    ];
});
بعد از ۵ تلاش ناموفق، حساب به مدت ۱۵ دقیقه قفل شود (Cache). قفل باید بر اساس شناسه کاربر (email/phone) باشد، نه فقط IP.

- هنگام ثبت‌نام، شماره موبایل و ایمیل باید یکتا باشند.

5.4 محدودیت تعداد دستگاه (در زمان ورود):
public function login(array $credentials, string $deviceId, string $deviceName = null, ?string $pushToken = null)
{
    // ...
    $maxDevices = $user->hasActivePremiumSubscription() ? 5 : 3;
    $activeDevices = $user->devices()->where('is_active', true)->count();
    if ($activeDevices >= $maxDevices) {
        throw new DeviceLimitExceededException('تعداد دستگاه‌های فعال بیش از حد مجاز است');
    }
    $device = $user->devices()->updateOrCreate(
        ['device_id' => $deviceId],
        ['device_name' => $deviceName, 'is_active' => true, 'last_activity' => now()]
    );
    if ($pushToken) {
        $user->pushSubscriptions()->updateOrCreate(
            ['push_token' => $pushToken],
            ['platform' => request()->header('X-Platform', 'unknown'), 'user_device_id' => $device->id]
        );
    }
    $token = $user->createToken('auth-token')->plainTextToken;
    return $token;
}

5.5 خروج از سیستم و مدیریت دستگاه‌ها:
- وب: Auth::logoutOtherDevices($password)

- کاربر باید بتواند لیست دستگاه‌های فعال خود را ببیند و یک دستگاه را غیرفعال کند (منجر به revoke توکن‌های مربوطه شود).

class SendOtpNotification extends Notification {
    use Queueable;
    public function __construct(public string $code) {}
    public function via($notifiable) { return ['sms']; }

class SmsChannel {

9.1 سرویس WalletService با قفل تراکنش:
public function deposit(User $user, float $amount, string $gateway, string $referenceId, string $description): Transaction
{
    return DB::transaction(function () use ($user, $amount, $gateway, $referenceId, $description) {
        $user = User::whereKey($user->id)->lockForUpdate()->first();
        $transaction = Transaction::create([
            'user_id' => $user->id,
            'type' => 'deposit',
            'amount' => $amount,
            'status' => 'success',
            'gateway' => $gateway,
            'reference_id' => $referenceId,
            'description' => $description,
            'balance_after' => $user->wallet_balance + $amount,
        ]);
        $user->wallet_balance += $amount;
        $user->save();
        return $transaction;
    });
}

public function withdraw(User $user, float $amount, string $description): Transaction
{
    return DB::transaction(function () use ($user, $amount, $description) {
        $user = User::whereKey($user->id)->lockForUpdate()->first();
        // بررسی محدودیت روزانه
        $todayWithdrawals = Transaction::where('user_id', $user->id)
            ->where('type', 'withdraw')
            ->whereDate('created_at', today())
            ->sum('amount');
        if (($todayWithdrawals + $amount) > config('wallet.withdraw_daily_limit')) {
            throw new WithdrawalLimitExceededException('محدودیت برداشت روزانه');
        }
        if ($amount > config('wallet.withdraw_amount_limit')) {
            throw new WithdrawalAmountLimitExceededException('مبلغ برداشت بیش از حد مجاز است');
        }
        if ($user->wallet_balance < $amount) {
            throw new InsufficientFundsException('موجودی کافی نیست');
        }
        $transaction = Transaction::create([
            'user_id' => $user->id,
            'type' => 'withdraw',
            'amount' => $amount,
            'status' => 'success',
            'description' => $description,
            'balance_after' => $user->wallet_balance - $amount,
        ]);
        $user->wallet_balance -= $amount;
        $user->save();
        return $transaction;
    });
}

9.2 پرداخت ترکیبی (کیف پول + درگاه):
- اگر مبلغ سفارش بیشتر از موجودی کیف پول باشد، کیف پول کسر و مابقی از درگاه پرداخت می‌شود.
- برای مدیریت صحیح، یک state machine با وضعیت‌های زیر در نظر گرفته شود:
  - pending_wallet_deduction
  - wallet_deducted
  - gateway_pending
  - gateway_success
  - gateway_failed

- در صورت شکست درگاه، تراکنش جبرانی (refund) برای کیف پول انجام شود.

9.3 Idempotency:
- قبل از شروع پرداخت، یک idempotency_key یکتا (UUID) توسط سرور تولید و در تراکنش ذخیره کنید.
- کلید به کلاینت برگردانده می‌شود. در درخواست‌های تکراری با همان کلید، اگر تراکنش هنوز در حالت pending است، پاسخ قبلی برگردانده شود؛ اگر success/failed است، خطای 409 با وضعیت فعلی.
- طول عمر idempotency_key حداکثر ۲۴ ساعت (ستون expires_at).

10.2 امضای دیجیتال برای Webhook و Callback:
- هر درگاه یک webhook_secret و یک callback_secret مشترک دارد.
- امضا: HMAC-SHA256(body, secret) در هدر X-Signature.
- برای callback، ممکن است درگاه امضا ارسال نکند؛ در این صورت باید حتماً وضعیت تراکنش را با API درگاه استعلام کنید.
- نمونه:
public function validateSignature(Request $request)
{
    $secret = config("payment.gateways.{$this->gatewayName}.webhook_secret")
        ?? config("payment.gateways.{$this->gatewayName}.callback_secret");
    $signature = $request->header('X-Signature');
    $calculated = hash_hmac('sha256', $request->getContent(), $secret);
    if (!hash_equals($signature, $calculated)) {
        abort(401, 'Invalid signature');
    }
}

11.1 سرویس DiscountService با کنترل همزمانی اتمی:
public function apply(User $user, string $code, float $amount): array
{
    return DB::transaction(function () use ($user, $code, $amount) {
        $discount = DiscountCode::where('code', $code)
            ->where('is_active', true)
            ->where(function ($q) {
                $q->whereNull('starts_at')->orWhere('starts_at', '<=', now());
            })
            ->where(function ($q) {
                $q->whereNull('expires_at')->orWhere('expires_at', '>=', now());
            })
            ->lockForUpdate()
            ->firstOrFail();

        if ($discount->user_id && $discount->user_id !== $user->id) {
            throw new DiscountNotValidException('این کد تخفیف برای شما معتبر نیست');
        }
        if ($amount < $discount->min_order_amount) {
            throw new DiscountNotValidException('مبلغ سفارش کمتر از حداقل لازم است');
        }
        if ($discount->usage_limit && $discount->usage_count >= $discount->usage_limit) {
            throw new DiscountNotValidException('ظرفیت استفاده از کد تکمیل شده است');
        }
        $alreadyUsed = DiscountUsage::where('discount_code_id', $discount->id)
            ->where('user_id', $user->id)
            ->exists();
        if ($alreadyUsed && !$discount->user_id) {
            throw new DiscountNotValidException('شما قبلاً از این کد استفاده کرده‌اید');
        }

        // محاسبه مبلغ تخفیف
        $discountAmount = $discount->type === 'percentage'
            ? ($amount * $discount->value / 100)
            : $discount->value;
        if ($discount->max_discount) {
            $discountAmount = min($discountAmount, $discount->max_discount);
        }

        return [
            'discount' => $discount,
            'discount_amount' => $discountAmount,
            'final_amount' => $amount - $discountAmount,
        ];
    });
}

public function recordUsage(User $user, DiscountCode $discount, float $discountAmount, ?int $transactionId = null): void
{
    return DB::transaction(function () use ($user, $discount, $discountAmount, $transactionId) {
        // ثبت استفاده
        DiscountUsage::create([
            'discount_code_id' => $discount->id,
            'user_id' => $user->id,
            'transaction_id' => $transactionId,
            'discount_amount' => $discountAmount,
        ]);

        // افزایش اتمی شمارنده استفاده
        DiscountCode::where('id', $discount->id)
            ->where(function ($query) {
                $query->whereNull('usage_limit')
                    ->orWhereRaw('usage_count < usage_limit');
            })
            ->increment('usage_count');
    });
}

public function sendOtp(Request $request)
{
    // برای وب کپچا الزامی است
    if (!$request->is('api/*')) {
        $request->validate(['g-recaptcha-response' => 'required|captcha']);
    }

    // باطل کردن همه OTPهای قبلی همین phone و type
    Otp::where('phone', $request->phone)
        ->where('type', $request->type)
        ->where('used', false)
        ->update(['used' => true]);

    $code = random_int(100000, 999999);
    $hash = Hash::make($code);
    Otp::create([
        'user_id' => $request->user()?->id,
        'phone' => $request->phone,
        'code_hash' => $hash,
        'type' => $request->type,
        'expires_at' => now()->addMinutes(5),
    ]);

    // ارسال از طریق Notification و صف
    $user = User::where('phone', $request->phone)->first();
    if ($user) {
        $user->notify((new SendOtpNotification($code))->onQueue('sms'));
    } else {
        Notification::route('sms', $request->phone)
            ->notify(new SendOtpNotification($code));
    }
    return response()->json(['message' => 'کد تأیید ارسال شد']);
}

12.4 تأیید OTP با قفل تصاعدی مبتنی بر Cache:
public function verifyOtp(Request $request)
{
    $otp = Otp::where('phone', $request->phone)
        ->where('type', $request->type)
        ->where('used', false)
        ->latest()
        ->firstOrFail();

    $cacheKey = 'otp_lock_'.$request->phone.'_'.$request->type;
    $lockSeconds = Cache::get($cacheKey);
    if ($lockSeconds) {
        abort(429, "تعداد تلاش‌های ناموفق زیاد است. لطفاً {$lockSeconds} ثانیه صبر کنید.");
    }

    if (now()->gt($otp->expires_at)) {
        abort(422, 'کد منقضی شده است');
    }

    if (!Hash::check($request->code, $otp->code_hash)) {
        // شمارنده تلاش ناموفق در Cache (با TTL 15 دقیقه)
        $attempts = Cache::increment('otp_attempts_'.$request->phone.'_'.$request->type, 1);
        if ($attempts >= 3 && $attempts < 6) {
            Cache::put($cacheKey, 300, now()->addMinutes(5));
        } elseif ($attempts >= 6 && $attempts < 10) {
            Cache::put($cacheKey, 3600, now()->addHour());
        } elseif ($attempts >= 10) {
            Cache::put($cacheKey, 86400, now()->addDay());
        }
        abort(422, 'کد نامعتبر است');
    }

    // تأیید موفق: حذف قفل و شمارنده تلاش
    Cache::forget($cacheKey);
    Cache::forget('otp_attempts_'.$request->phone.'_'.$request->type);

    $otp->update(['used' => true]);
    // ادامه فرآیند...
}

        }
        $response = [
            'type' => url('/errors/' . $status),
            'title' => $title,
            'status' => $status,
            'detail' => $detail,
            'instance' => $request->fullUrl(),
        ];
        if (method_exists($exception, 'errors')) {
            $response['errors'] = $exception->errors();
        }
        return response()->json($response, $status);
    }
    return parent::render($request, $exception);
}
